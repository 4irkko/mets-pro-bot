# МЭТС — Telegram редактор и мониторинг (экспериментальная сборка)

## Статус
Это **не проверенная на реальном МЭТС** версия. Проверены синтаксис и локальные тесты, но сайт возвращает HTTP 403 из веб-среды и недоступен по DNS из среды сборки. Мониторинг главной страницы — экспериментальный: ссылки на лоты могут отсутствовать в HTML, а лента событий может иметь другую структуру. Полноценный разбор недвижимости и оценка рынка земли **не реализованы**; бесплатная оценка из старого прототипа работает только для распознанных автомобилей и лишь при наличии подтверждаемых аналогов. Автоматической публикации без модерации нет.

## Установка на Railway
1. Создайте бота в BotFather и сохраните токен.
2. Узнайте свой числовой Telegram ID через @userinfobot.
3. Загрузите содержимое этой папки (не родительский ZIP) в приватный GitHub репозиторий.
4. Railway → New Project → Deploy from GitHub Repo; Railway обнаружит Dockerfile.
5. Добавьте переменные `BOT_TOKEN`, `OWNER_IDS`, `DB_PATH=/data/mets.sqlite3`, `MONITOR_INTERVAL_SECONDS=1800`.
6. Добавьте **persistent volume**, смонтированный в `/data`, иначе черновики и история новых лотов пропадут при перезапуске.
7. Запустите бота и отправьте `/start` в личном чате.
8. Добавьте бота администратором канала с правом публикации, затем отправьте `/channel @имя_канала` или `/channel -100...`.
9. Отправьте ссылку на лот. Если доступ к карточке заблокирован, бот честно сообщит об ошибке.
10. `/monitor_on` включает экспериментальный мониторинг раз в 30 минут. **Первый успешный опрос только запоминает уже существующие ссылки и ничего не рассылает.**

## Команды
`/start`, `/channel @канал`, `/footer ваш текст`, `/footer_clear`, `/draft 12`, `/cancel`, `/monitor_on`, `/monitor_off`.

## Важные ограничения
- Не добавляйте бота в чужой канал: он проверяет права на публикацию.
- Публикация — сначала текст, затем фото отдельным альбомом. Telegram не позволяет прикрепить длинный текст к альбому без ограничения подписи.
- После сетевого таймаута Telegram публикация может фактически состояться; перед повторной попыткой проверьте канал.
- Не запускайте одновременно две реплики бота с одной базой и токеном.
- Рыночные ориентиры — не оценочный отчёт и не цена сделки.
- Интервал мониторинга не гарантирует обнаружение всех лотов. Нужна проверка реального формата ленты и нескольких последовательных запусков.
- Без подтверждённого извлечения страницы пост не создаётся.
